Current Architecture Build

Autonoma-Ops: Automated Invoice Reconciliation Engine

In Development

FastAPI • Redis/RQ • PostgreSQL • Gemini OCR • Docker • Alembic

An event-driven pipeline designed to eliminate manual invoice-to-inventory reconciliation:

  • Document Ingestion: FastAPI endpoint accepting multi-format vendor uploads (PDF, Excel, images).
  • Async Task Decoupling: Redis Queue (RQ) worker offloading OCR extraction and line-item reconciliation from the web server thread.
  • Audit & Discrepancy Engine: Gemini Vision structured JSON outputs compared against internal inventory records, auto-flagging line-item variances over 2%.
  • Production Deployment: Containerized via Docker Compose with Alembic migrations and GitHub Actions CI/CD test pipelines.
